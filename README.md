# sql-practice
Репозиторий с задачами по SQL для подготовки к собеседованиям
на аналитика данных / продуктового аналитика.

## Темы

- [х] Оконные функции: ROW_NUMBER, RANK, DENSE_RANK
- [x] LAG / LEAD, сравнение с предыдущим периодом
- [] CTE и подзапросы

## Файлы

- `00.sql` — задачи с leetcode, выбранные для дополнительной практики
- `01_ranking.sql` — функции ранжирования
- `02_lag_lead.sql` — динамика по месяцам
- `03_sum_over.sql` —  агрегирующие функции
- `04_cte.sql` — многослойные запросы



Для задач с 3+ логическими шагами предпочитаю CTE: читается сверху вниз, каждый шаг можно проверить отдельно, легче ревьюить. Для 1–2 шагов подзапрос в FROM короче и не хуже. Исключение — если CTE используется один раз и в старых версиях PostgreSQL, где CTE был оптимизационным барьером; в SQLite и PostgreSQL 12+ это уже не проблема.
